🎓 CGPA Booster – Student Productivity Dashboard

A responsive student productivity web application designed to help students manage their academic performance, organize study schedules, and track learning progress.

🚀 Built With

HTML5

CSS3

Vanilla JavaScript

Browser LocalStorage
✨ Features

🔐 Login & Signup: Basic authentication using LocalStorage.

📊 Student Dashboard: Personalized academic dashboard.

🧮 CGPA Calculator: Calculate and manage CGPA.

📅 Study Schedule: Organize daily study activities.

📝 Daily Quiz: Subject-based daily quizzes.

🧠 Topic Mastery Tracking: Track topic-wise learning progress.

📈 Quiz History: Monitor quiz performance and accuracy.

🔥 Study Streak: Track consistent study habits.

📚 Subject Management: Manage academic subjects.

🎯 Goals: Set and track study goals.

🔗 Resources: Access useful study resources.

🔍 Search: Quickly find information.

🌙 Dark Mode: Switch between light and dark themes.

📱 Responsive Design: Works across desktop and mobile screens.
